
# Gestion des tâches

## Présentation

Gestion des tâches est une application web développée avec React.
Elle permet d'organiser et de suivre les tâches facilement.

## Fonctionnalités

- Ajouter une tâche.
- Modifier une tâche.
- Supprimer une tâche.
- Ajouter une date de début et une date de fin.
- Attribuer un statut à chaque tâche.
- Filtrer les tâches par statut.
- Rechercher une tâche.
- Vérifier les champs et les dates.
- Sauvegarder les tâches avec localStorage.
- Afficher les statistiques.
- Visualiser les statuts avec un graphique.
- Interface responsive.

## Technologies utilisées

- React
- JavaScript
- CSS
- Recharts
- LocalStorage

## Installation

1. Télécharger le projet.
2. Ouvrir le terminal dans le dossier du projet.
3. Installer les dépendances :

npm install

4. Installer Recharts :

npm install recharts

5. Lancer le projet :

npm run dev

6. Ouvrir le lien affiché dans le terminal.
